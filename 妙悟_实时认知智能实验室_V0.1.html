注册本地模型

本地模型指：由实验平台所在机器直接加载并执行的模型。不包括 HTTP 服务，也不包括大语言模型 / 多模态大模型。
本地加载测试正式开发时应真正尝试加载模型，并返回成功/失败和错误信息。

注册模型服务

模型服务按 Provider 管理连接。先配置 Provider / API 地址 / API Key，再填写或选择该 Provider 下可用的模型名称。
服务测试正式开发时应测试 API 连通性，并对默认模型发起一次最小请求。
